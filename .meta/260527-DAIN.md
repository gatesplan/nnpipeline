## 2. 문제 정의

[확정] 동기는 두 가지로 명시됨 [근거, 논문 §I]:
- 금융 시계열은 **non-stationary + multimodal** — 시장 변동성·종목 간 가격 레벨 차이로 글로벌 z-score가 부적합.
- 기존 정규화는 학습 전에 고정된 통계로 처리 → train/inference에서 분포 드리프트 발생 시 무효화됨.

[확정] 핵심 주장: 정규화 자체를 **end-to-end 학습 가능한 neural layer**로 만든다 [근거, 논문 abstract].

## 3. 아키텍처 — 3 sublayer

입력 표기: $\{\mathbf{X}^{(i)} \in \mathbb{R}^{d \times L}; i=1,...,N\}$ — N개의 시계열, 각 시계열은 L개의 d차원 측정. $\mathbf{x}^{(i)}_j \in \mathbb{R}^d$가 시계열 $i$의 시점 $j$에서의 측정 [근거, 논문 §II].

### (1) Adaptive Shifting (centering)

Summary aggregator (단순 시간 평균):

$$\mathbf{a}^{(i)} = \frac{1}{L}\sum_{j=1}^{L} \mathbf{x}^{(i)}_j \in \mathbb{R}^d \quad (Eq.\ 2)$$

Shifting operator는 summary의 선형 변환:

$$\alpha^{(i)} = \mathbf{W}_a \mathbf{a}^{(i)} \in \mathbb{R}^d \quad (Eq.\ 3)$$

[확정] **non-linearity 없음** — saturation 회피 + 정규화 안 된 raw 입력을 받아도 학습 안정성 확보 목적. $\mathbf{W}_a \in \mathbb{R}^{d \times d}$는 채널 간 cross-correlation을 학습할 수 있게 함 [근거, 논문 §II].

### (2) Adaptive Scaling (standardization)

Shifting 이후의 표준편차를 다시 summary로:

$$b^{(i)}_k = \sqrt{\frac{1}{L}\sum_{j=1}^{L}\bigl(x^{(i)}_{j,k} - \alpha^{(i)}_k\bigr)^2}, \quad k=1,...,d \quad (Eq.\ 4)$$

Scaling operator도 선형:

$$\beta^{(i)} = \mathbf{W}_b \mathbf{b}^{(i)} \in \mathbb{R}^d \quad (Eq.\ 5)$$

정규화 식 (Hadamard 나눗셈 $\oslash$):

$$\tilde{\mathbf{x}}^{(i)}_j = \bigl(\mathbf{x}^{(i)}_j - \alpha^{(i)}\bigr) \oslash \beta^{(i)} \quad (Eq.\ 1)$$

### (3) Adaptive Gating

세 번째 summary는 정규화된 시리즈의 평균:

$$\mathbf{c}^{(i)} = \frac{1}{L}\sum_{j=1}^{L} \tilde{\mathbf{x}}^{(i)}_j \in \mathbb{R}^d \quad (Eq.\ 8)$$

Gating signal:

$$\gamma^{(i)} = \mathrm{sigm}(\mathbf{W}_c \mathbf{c}^{(i)} + \mathbf{d}) \in \mathbb{R}^d \quad (Eq.\ 7)$$

최종 출력:

$$\tilde{\tilde{\mathbf{x}}}^{(i)}_j = \tilde{\mathbf{x}}^{(i)}_j \odot \gamma^{(i)} \quad (Eq.\ 6)$$

[확정] gating은 **task에 부적합한 채널을 부분적으로 억제**하는 역할 — 특히 과도한 분산을 가진 채널 [근거, 논문 §II].

## 4. 학습

End-to-end backprop. 단, sublayer별로 **별도 learning rate** 사용 — gradient 스케일이 sublayer 간 크게 다르기 때문 [근거, 논문 Eq. 9 및 §III].

초기화 [근거, 논문 §III "Hyper-parameters"]:
- $\mathbf{W}_a = \mathbf{W}_b = \mathbf{I}_{d \times d}$ (identity)
- $\mathbf{W}_c, \mathbf{d}$는 정규분포 랜덤
- 옵티마이저: RMSProp
- FI-2010 기준 $\eta = 10^{-4}$, $\eta_a / \eta_b / \eta_c = 10^{-6}/10^{-3}/10$ (MLP) 등 — sub-layer별로 6~9 자릿수 차이 발생

## 5. 실험 데이터

### FI-2010 (LOB) [근거, 논문 §III]

- 출처: Helsinki Exchange (Nasdaq Nordic), 5개 핀란드 기업
- 기간: 2010-06-01 ~ 2010-06-14 (10 영업일)
- 총 4.5M limit order → 453,975개 144차원 feature vector로 전처리
- 라벨: mid price direction (up/stationary/down), horizon 10 또는 20 timestep, stationary threshold $\pm 0.01\%$ (10-step) / $\pm 0.02\%$ (20-step)
- 평가: anchored evaluation (1일차 train→2일차 test, 1·2일차 train→3일차 test, ... 총 9회 반복)
- 입력 윈도: 가장 최근 15 step × 144 feature

### Household Power Consumption [근거, 논문 §III]
- 7차원 feature × 20분 윈도, 다음 10분 평균 소비량 증가/감소 이진 분류

## 6. 비교 결과 (Macro F1 / Cohen κ)

### FI-2010 ablation, MLP backbone, horizon=10 [근거, 논문 Table I]

| 정규화 | Macro F1 | Cohen κ |
|---|---|---|
| No norm | $12.71 \pm 13.22$ | 0.0010 |
| z-score | $53.76 \pm 0.99$ | 0.3059 |
| Sample avg | $41.80 \pm 3.58$ | 0.1915 |
| Batch Norm | $52.72 \pm 1.94$ | 0.2893 |
| Instance Norm | $59.13 \pm 2.94$ | 0.3717 |
| DAIN (1) only | $57.37 \pm 3.16$ | 0.3536 |
| DAIN (1+2) | $66.71 \pm 2.02$ | 0.4896 |
| **DAIN (1+2+3)** | **$66.92 \pm 1.70$** | **0.4934** |

[확정] DAIN(1+2+3)이 Instance Norm 대비 Cohen κ를 32.7% 향상 [근거, 논문 Table I].

### Full evaluation, MLP+horizon=10 [근거, 논문 Table II]

| 정규화 | Macro F1 | Cohen κ |
|---|---|---|
| z-score | 54.65 | 0.3206 |
| Instance Norm | 59.67 | 0.3827 |
| **DAIN** | **68.26** | **0.5145** |

### 분포 시프트 강건성 [근거, 논문 §III 마지막 단락]

Household 데이터에 평가 시점에만 평균값의 3배를 모든 측정에 더하는 인위적 시프트 적용:
- z-score MLP: 75.39% → 56.56% (−18.83%p **붕괴**)
- DAIN MLP: 78.59% → 78.21% (−0.38%p)

[확정] DAIN은 inference 시점의 instance마다 통계를 추정하기 때문에 분포 시프트에 robust [근거, 논문 결과].

### GRU와의 상호작용 [근거, 논문 §III ablation 해석]

- gating layer(3)는 MLP/CNN에서는 2.5% 추가 향상 / GRU에서는 효과 없음 (오히려 약간 하락)
- [확정] GRU 자체에 gating이 있으므로 중복 → "백본이 이미 gating을 가지면 DAIN의 3번 sublayer는 생략 가능"

## 7. 추가 파라미터·복잡도

- $\mathbf{W}_a, \mathbf{W}_b, \mathbf{W}_c \in \mathbb{R}^{d \times d}$ + bias $\mathbf{d} \in \mathbb{R}^d$
- 총 추가 파라미터 $\approx 3d^2 + d$
- FI-2010 ($d=144$) 기준 약 62K parameter — backbone(512-unit MLP의 입력층만 약 1.1M parameter) 대비 미미 [추측, 논문 직접 명시 없음]

## 8. 저자가 명시한 한계

- learning rate 튜닝의 민감성 — multiplicative weight update 등 안정화 학습법이 future work [근거, 논문 §IV].
- Summary aggregator가 단순 시간 평균에 의존 — bag-of-features류로 확장 여지 [근거, 논문 §IV].
- Mode 정보를 의도적으로 폐기함 — 향후 mode embedding 결합 가능 [근거, 논문 §IV].

## 9. 가격 전용 네트워크 설계에서의 시사점

[추측] Channel-wise correlation을 $\mathbf{W}_a$로 학습 → OHLC 채널 간 구조적 관계(H-L range, C-O return 등)를 정규화 단에서 일부 포착 가능. 단, OHLC 부등식 제약 $H \geq \max(O,C)$, $L \leq \min(O,C)$ 은 보장 안 됨.

[추측] gating(3)이 거래량(V) 채널을 자동으로 dampening할 가능성 — V는 가격과 스케일·통계가 완전히 다르므로 잠재적으로 sigmoid가 작게 닫힐 수 있음. 실측 필요 [추적필요].

[확정] DAIN 자체는 OHLC 구조나 가격 통계(fat-tail, heteroscedasticity)를 명시적으로 모델링하지 않음 — 어디까지나 "분포 시프트 대응 일반 정규화" 범주. 가격 전용 receptor로 사용하려면 OHLC 제약을 강제하는 추가 layer 필요.
