## 2. 문제 정의

[확정] 기존 reversible normalization(RevIN, Dish-TS, SAN)의 핵심 한계 — **mean·variance만으로는 seasonal pattern의 변화를 잡을 수 없다** [근거, 논문 abstract + §1].

[확정] 논문 Fig.1의 motivating example — 주파수가 선형적으로 감쇠하는 사인 신호. 세 구간이 평균·분산은 동일하지만 Fourier 주파수가 다름 ($\mu_1\sigma_1 = \mu_2\sigma_2 = \mu_3\sigma_3$, $f_1 \ne f_2 \ne f_3$). 통계 기반 정규화는 이 변화를 인식하지 못함 [근거, 논문 Fig.1 캡션].

[확정] 동시에 기존 frequency 기반 모델(TimesNet, Koopa, FEDformer)도 **principal frequency가 sequence 전체에 걸쳐 고정**이라는 가정을 깔고 있어 변화하는 주파수를 못 잡음 [근거, 논문 §1, §2.2].

## 3. 아키텍처

전체 구조는 RevIN의 대칭(정규화↔역정규화) 패러다임을 그대로 차용하되, **통계량 대신 Fourier 주성분을 제거·복원**하는 형태로 교체 [근거, 논문 §3, Fig.2].

### Frequency Residual Learning (FRL) — 정규화

입력 $\mathbf{X}_t \in \mathbb{R}^{L \times D}$ (lookback 길이 L, D차원). 채널 독립으로 1D DFT 적용 [근거, 논문 §3.1, Eq.1]:

$$\mathbf{Z}_t = \text{DFT}(\mathbf{X}_t) \quad \text{(complex } \mathbb{C}^{T \times D}\text{)}$$
$$\mathcal{K}_t = \text{TopK}(\text{Amp}(\mathbf{Z}_t))$$
$$\mathbf{X}^{non}_t = \text{IDFT}(\text{Filter}(\mathcal{K}_t, \mathbf{Z}_t))$$

[확정] **각 instance마다** top-K 주성분을 선택 (global이 아님). Filter는 $\mathcal{K}_t$에 속한 주파수만 통과시키는 binary mask. IDFT로 시간 도메인의 "non-stationary 성분"을 복원함 [근거, 논문 §3.1].

Residual:
$$\mathbf{X}^{res}_t = \mathbf{X}_t - \mathbf{X}^{non}_t \quad (Eq. 2)$$

복잡도 [근거, 논문 §3.1]: DFT/IDFT $O(L\log L)$, TopK/Filter $O(L+K)$. GPU 친화적.

### GPU 친화 의사코드 [근거, 논문 Appendix A.2]

```python
def norm(x, k):
    # x: (BxNxL) batchified multivariate input
    z = torch.fft.rfft(x, dim=2)
    ks = torch.topk(z.abs(), k, dim=2)
    top_k_indices = ks.indices
    mask = torch.zeros_like(z)
    mask.scatter_(2, top_k_indices, 1)
    z_m = z * mask
    x_m = torch.fft.irfft(z_m, dim=2).real
    x_n = x - x_m   # residual
    return x_n
```

### Forecast & Denormalization

Backbone $g_\theta$가 residual만 받아 residual을 예측 [근거, 논문 §3.2, Eq.3]:
$$\hat{\mathbf{Y}}^{res}_t = g_\theta(\mathbf{X}^{res}_t)$$
$$\hat{\mathbf{Y}}_t = \hat{\mathbf{Y}}^{res}_t + \hat{\mathbf{Y}}^{non}_t$$

여기서 $\hat{\mathbf{Y}}^{non}_t$가 **non-stationary shift forecasting의 핵심**.

### Non-stationary shift forecasting — MLP $q_\phi$

[확정] RevIN의 가정("input·output의 non-stationary 부분이 동일")을 직접 깨고, **MLP로 미래의 top-K 주파수 성분을 예측** [근거, 논문 Eq.4]:

$$\hat{\mathbf{Y}}^{non}_t = q_\phi(\mathbf{X}^{non}_t, \mathbf{X}_t) = \mathbf{W}_3\,\text{ReLU}\bigl(\mathbf{W}_2\,\text{Concat}(\text{ReLU}(\mathbf{W}_1 \mathbf{X}^{non}_t), \mathbf{X}_t)\bigr)$$

[확정] $\mathbf{X}_t$를 concat하는 이유: $\mathbf{X}^{non}_t$만으로는 top-K 외 주파수의 변화를 못 잡으므로 원본 입력을 보조 신호로 투입 [근거, 논문 §3.2 마지막 문단].

[확정] MLP 구조 — hidden sizes [64, 128, 128], 즉 사실상 3-layer MLP [근거, 논문 §4.1 Implementation].

### Loss

[확정] Multi-task: forecast loss + non-stationary prior loss [근거, 논문 Eq.5]:

$$\phi, \theta = \arg\min_{\phi,\theta} \sum_t \bigl[\mathcal{L}^{nonstat}_\phi(\mathbf{Y}^{non}_t, \hat{\mathbf{Y}}^{non}_t) + \mathcal{L}^{forecast}_{\theta,\phi}(\mathbf{Y}_t, \hat{\mathbf{Y}}_t)\bigr]$$

둘 다 MSE.

## 4. 실험 설정 [근거, 논문 §4.1]

- 8 데이터셋: ETTh1/h2/m1/m2, Electricity, ExchangeRate, Traffic, Weather (금융 데이터는 ExchangeRate가 유일)
- 4 backbone: DLinear, FEDformer, Informer, SCINet
- 입력 $L=96$ 고정, 예측 $H \in \{96, 168, 336, 720\}$
- 데이터셋별 K (Table 1): Weather/Exchange=2, Electricity=3, ETTh2=3, ETTh1=4, ETTm2=5, ETTm1=11, Traffic=30 — Traffic은 seasonality variation이 14.225로 가장 크고 K도 가장 큼

### K 선택 규칙

[확정] $K$ = training set에서 "최대 amplitude의 10% 이상"인 주파수 성분 개수 [근거, 논문 §4.1, Appendix A.1].

진폭이 선형 증가하는 9개 사인 신호 합성. FAN의 MAE/MSE 개선률 19.75~32.45% / 23.76~47.04%. 주성분 신호 수가 늘수록 baseline(RevIN/Dish-TS/SAN)은 정체하나 FAN은 향상.

### Ablation [근거, 논문 §4.5, Table 4]

- **w/o predict** (단순히 $\mathbf{X}^{non}_t$를 그대로 복원, RevIN 식): 큰 폭 성능 하락 → MLP가 핵심.
- **pure backbone** (정규화 자체 제거): 가장 나쁨.
- **w/o backbone** (residual 학습 없이 $\hat{\mathbf{Y}}^{non}_t$만): 2위 — FAN의 frequency 학습이 이미 주요 패턴을 잡음을 시사.
- **Instance-wise vs Global frequency 선택** (Table 5): Electricity 18.50%, Traffic 10.29% MSE 개선 → instance-wise가 핵심.

## 6. 이론적 정당화 [근거, 논문 Appendix C]

- DFT 주성분 K개 제거 시 잔차의 amplitude variance가 감소 (Eq.15: $\text{Var}(\mathbf{a}^{res}) < \text{Var}(\mathbf{a})$).
- Parseval 정리로 시간 도메인 variance ≈ 주파수 도메인 energy 합 (Eq.17).
- 따라서 top-K 제거 시 시간 도메인 variance도 큰 폭으로 감소 (Eq.22: $\text{Var}[\mathbf{x}^{res}] \ll \text{Var}[\mathbf{x}]$).
- Zero frequency = 평균 (Eq.16), 이를 제거하는 것이 traditional 'detrending'에 해당 (Eq.20).

## 7. 한계 [근거, 논문 Appendix F]

1. [확정] **Over-stationary 위험** — 너무 많은 주파수를 제거하면 backbone이 학습할 dynamics가 사라짐.
2. [확정] **K 선택 어려움** — 10% rule이나 search 기반에 의존 → 잘못 고르면 under/over-stationary.
3. [확정] **주기성 가정** — 유한 개의 사인 기저로 표현 불가능한 신호(square wave 등) 처리 한계.
4. [확정] **Future work**: instance-specific K 자동 결정, 동적 stationarity 제어, 비주기 waveform 추출.

## 9. 가격 전용 네트워크 설계에서의 시사점

[확정] **가격·환율 시계열에서 RevIN보다 명확히 우수**한 결과 — Exchange 데이터 51.27% 개선이 직접 증거.

[추측] 가격 데이터는 명확한 주기성(일중 세션, 주간 패턴, 월간 옵션 만기 사이클)을 가지므로 FAN의 frequency 분해가 자연스럽게 맞물림. 단, **주식·가상자산은 매우 noisy하고 dominant frequency가 약함** → K 자동 선택 메커니즘이 더욱 필요 [추적필요: 실측].

[확정] 입력 차원 채널 독립 처리 → OHLCV 5채널에 그대로 적용 가능. 거래량 채널은 가격 채널과 다른 주파수 구조(예: open/close auction spike)를 가지므로 채널별 K가 다른 게 자연스러움 [추측].

[추측] 가격 전용 receptor 설계 시 FAN을 첫 layer로 두고, residual에 OHLC 부등식 제약 reparameterization을 얹는 stacked 구조가 후보. 또는 FAN의 MLP $q_\phi$를 가격 특화 모듈(σ-Cell 같은 GARCH 셀)로 대체하는 방향 [추적필요].

[확정] FAN의 Over-stationary 한계는 가격에서 더 위험 — 가격에서 dominant low-frequency는 trend 그 자체(매매 신호의 핵심) → K를 작게 잡거나 trend는 별도 channel로 분리하는 변형이 필요.
