## 0. 왜 이 그룹이 가격 전용 네트워크에 중요한가

[확정] 가격 시계열의 두 가지 핵심 통계 특성:
1. **Non-stationarity** — 시장 변동성·체제 전환으로 인한 분포 드리프트
2. **Multimodality** — 종목·자산 간 가격 레벨·통계의 분산 (1$ 주식 vs 100$ 주식)

전통적 z-score/min-max는 이 두 특성에 대해 모두 부적합 — 학습 시 고정된 통계를 사용하므로 inference 시 분포가 이동하면 무효화됨 [근거, DAIN 논문 §I, FAN 논문 §1].

이 그룹은 **정규화 자체를 학습 가능 layer로 만들어 모델 안에 통합**하는 접근. 가격 전용 receptor의 가장 견고한 기반층이며, 현재 시계열 SOTA 전반의 사실상 표준이 됨 [확정, FAN 논문 §2.3].

## 1. 3종 비교표

| 항목 | DAIN (2019) | RevIN (2022) | FAN (2024) |
|---|---|---|---|
| 게재 | IEEE TNNLS / arXiv | ICLR 2022 | NeurIPS 2024 |
| 정규화 단 | shift + scale + gate (3 sublayer) | $(x-\mu)/\sigma$ + affine | DFT → top-K filter → IDFT 잔차 |
| 역정규화 | **없음** (분류 태스크용) | affine 역 → $\times\sigma$ → $+\mu$ | residual + 예측된 non-stationary |
| 통계 분리 방식 | 학습된 선형변환 ($W_a, W_b$) | per-instance per-channel mean/std (.detach) | per-instance top-K Fourier 성분 |
| 학습 가능 파라미터 | $W_a, W_b, W_c, d$ ($\approx 3d^2+d$) | $\gamma_c, \beta_c$ ($2C$개) | $W_1, W_2, W_3$ (3-layer MLP) |
| 시점 통합 단위 | sequence 전체 평균(summary aggregator) | sequence 평균/표준편차 | sequence FFT |
| Inductive bias | "분포 시프트는 평균·분산 시프트가 주" | 동일 | "분포 시프트는 trend + seasonality(주파수)" |
| 핵심 한계 | 회귀 출력 스케일 미복원 / lr 튜닝 까다로움 | seasonality·heavy-tail에 약함 | over-stationary 위험 / K 선택 |
| 검증 도메인 | FI-2010 LOB | ETT + Nasdaq | ETT + ExchangeRate 등 8종 |

## 2. 시간 흐름과 계보

```
DAIN (2019, FI-2010 LOB)
   학습형 instance 정규화의 출발점 — sublayer 3개 신경망
        │
        │ 회귀 태스크에서는 출력 스케일 복원이 필요
        ▼
RevIN (ICLR 2022)
   정규화·역정규화 대칭 구조 → forecasting 표준화
        │
        │ mean/var만으로는 seasonality 못 잡음
        ▼
FAN (NeurIPS 2024)
   주파수 도메인 분해 + MLP가 future frequency 예측
```

[확정] FAN은 명시적으로 DAIN[33]과 RevIN[17]을 인용하며 직계 후속작임을 밝힘 [근거, FAN 논문 §2.3].

## 3. 핵심 설계 결정의 축

### 3.1 무엇을 "non-stationary 정보"로 정의하는가

- DAIN: instance의 평균·표준편차 → 학습된 선형변환으로 변형
- RevIN: instance의 mean과 std
- FAN: instance의 top-K 주파수 amplitude·phase

[확정] **FAN의 일반화**가 가장 강함. zero frequency = 평균이므로 RevIN(mean 제거)은 FAN의 K=1 특수 case에 해당 [근거, FAN 논문 Appendix C.3 Eq.16].

### 3.2 역정규화 여부

- DAIN: 없음 → **분류(direction prediction)에는 적합, 회귀에는 부적합**
- RevIN: 대칭 affine 역변환 → 모든 forecasting에 표준
- FAN: residual + 별도 MLP가 예측한 non-stationary

[확정] 가격 회귀(다음 close 예측, return 예측) 태스크에서는 DAIN을 그대로 쓰면 출력 스케일이 안 맞음 — RevIN 또는 FAN을 써야 함.

### 3.3 학습 신호가 통계량을 거치는가

- DAIN: $W_a, W_b$ 자체가 학습 — 통계량 estimation에 backprop 통과
- RevIN: 통계량은 `.detach()` — 그래프 차단, affine만 학습
- FAN: 주파수 성분은 raw FFT (학습 안 됨), top-K 선택은 amplitude 기반 (학습 안 됨), MLP만 학습

[확정] RevIN의 .detach는 **안정성과 단순성**을 얻지만, heavy-tail에 약해지는 원인이기도 함. 통계량이 outlier 1~2개에 흔들리는데 backprop이 이를 보정할 신호를 받지 못함 [근거, FAN 논문 §1 한계 서술].

### 3.4 채널 간 상호작용

- DAIN: $W_a \in \mathbb{R}^{d \times d}$가 채널 간 cross-correlation 학습
- RevIN: 채널 독립 (channel-wise affine만)
- FAN: 채널 독립 (channel independence 명시 [근거, 논문 §3.1])

[확정] DAIN만 채널 간 상호작용 학습. OHLC 채널 간 구조적 관계(H-L = range, V-|C-O| 상관 등)를 정규화 단에서 일부 포착할 가능성 있음 [추측, 직접 실측 필요].

## 4. 가격 전용 receptor 설계에 대한 시사점

### 4.1 [확정] 베이스라인 선택

가격 전용 네트워크의 입력 정규화 layer로는 다음 우선순위를 추천:

1. **FAN** — Exchange 데이터에서 51.27% MSE 개선이라는 강한 실증. 가격의 주기성(일중·주간 세션)과 자연스럽게 맞물림.
2. **RevIN** — 가장 단순하고 검증된 표준. FAN을 시도하기 전 fair-comparison baseline.
3. **DAIN** — 회귀에는 부적합. 단, 가격 방향성 분류(up/down/stationary) 태스크에서는 채널 간 cross-correlation 학습이 장점.

### 4.2 [확정] 각각의 가격 적용 시 검증해야 할 사항

| 정규화 | 가격 데이터에서 검증 필요 |
|---|---|
| DAIN | 회귀 변형 (역정규화 추가) 가능성 / sublayer별 lr 6~9 자릿수 튜닝 부담 |
| RevIN | 극단치(flash crash, gap)에서 MSE 안정성 / fat-tail 손상 정도 |
| FAN | 과한 stationarity로 trend 신호 상실 위험 / K=낮을 때 거래량 채널 처리 / 가격 변동성 클러스터링이 단일 K로 잡히는지 |

### 4.3 [추측] 가격 특화로 확장할 만한 지점

- **OHLC 부등식 제약** — 세 정규화 모두 다루지 않음. RevIN/FAN 출력 뒤에 reparameterization layer (참조: Pseudo-PCA for OHLC, arXiv 2103.16908) 결합 가능
- **거래량 채널 별도 처리** — V는 가격과 통계가 완전히 다름. 채널별 다른 정규화 적용 또는 별도 K 선택 검토
- **Quantile head 결합** — 세 정규화 모두 점 추정 가정. 분산·꼬리 정보 회수를 위해 quantile loss 또는 mini SDE head와 결합 [근거, 모태 조사 E.4]
- **Volatility-aware gating** — DAIN의 gating sublayer를 가격 변동성 추정치로 driving하는 변형 (Volatility-conditioned gating)

### 4.4 [추측] 가격 receptor stack 후보

```
입력 OHLCV (T, 5)
   │
   ▼
[FAN] — per-channel top-K Fourier 분해, 채널별 K
   │   → residual + non-stationary
   ▼
[OHLC 제약 reparameterization] — $H \geq \max(O,C)$, $L \leq \min(O,C)$ 강제
   │   (Pseudo-PCA 또는 별도 학습형)
   ▼
[volatility-aware gating] — 변동성 estimator로 채널 게이팅
   │
   ▼
backbone (PatchTST / Mamba / iTransformer)
   │
   ▼
[FAN 역정규화] — 출력 스케일 복원
   │
   ▼
quantile head / SDE head
```

이는 [추측] 단계의 가설 — 실측 ablation 필요 [추적필요].

## 5. 미해결 의문

- [추적필요] RevIN/FAN의 heavy-tail 강건성 — 가격 데이터(특히 가상자산)의 큰 점프에서 정규화가 어떻게 깨지는지 실측 없음
- [추적필요] FAN K 자동 선택 — 가격에서 dominant frequency가 약하면 10% rule이 의미 있는가
- [추적필요] DAIN 회귀 변형 — 역정규화 layer 추가 시 분류 대비 성능 변화
- [추적필요] OHLCV에 FAN 적용 시 거래량 채널의 K 선택 효과 — V는 가격과 통계가 다르므로 채널별 다른 K가 자연스러운지
