# 금융 가격 전용 네트워크 조사

- 조사일: 2026-05-26
- 범위: 금융 가격(주식·암호화폐·FX 등) 시계열 예측 및 구조 특화 신경망
- 대상 시기: 2023-2026 (필요 시 토대 모델 포함)
- 조사 방식: 웹 검색(arXiv, 학회, 도메인 블로그) 기반 1차 수집. 모든 주장은 [근거, URL] 표기.

본 문서는 사용자가 "가격 데이터를 처리하는 전용 네트워크"를 직접 설계 중인 상황에서, 기존 알고리즘과 시계열 구조 자체에 부합하는 특수 아키텍처를 동시에 일별하기 위한 자료다.

## 0. 영역 분류

5개 축으로 정리한다.

1. Transformer 계열 (범용 시계열 + 금융 특화 변형)
2. SSM / Mamba / 비-Transformer 신규 시계열 모델
3. LOB(호가창) · 시장 미시구조 전용 아키텍처
4. 시계열 파운데이션 모델 + 가격·텍스트 멀티모달
5. 시계열 구조적 귀납 편향(Inductive Bias) 특화 아키텍처

## 1. Transformer 계열

### 1.1 범용 시계열 Transformer (가격 적용 활발)

- **Informer (AAAI 2021)**: ProbSparse self-attention으로 O(L log L) 복잡도, generative-style decoder로 long-sequence 예측. 비정상성·변동성 클러스터링은 명시적으로 다루지 않음 [근거, https://arxiv.org/abs/2012.07436]. 후속 Fourier-Mixed Window Attention으로 보완 [근거, https://arxiv.org/pdf/2307.00493].
- **Autoformer (NeurIPS 2021)**: 이동평균 기반 series decomposition + FFT 기반 Auto-Correlation. 6개 벤치마크 38% MSE 개선 [근거, https://arxiv.org/abs/2106.13008]. 가격은 계절성이 약해 raw 적용 한계 [추측].
- **FEDformer (ICML 2022)**: Frequency-enhanced block, Autoformer 대비 univariate에서 22%+ 개선 [근거, https://medium.com/@serana.ai/transformers-for-time-series-forecasting-e5e0327e78be]. 2025 "FEDformer-Based Hybrid Framework"가 잔차 이상치 탐지+위험 head 결합으로 금융 직접 적용 [근거, https://arxiv.org/pdf/2511.12951].
- **PatchTST (ICLR 2023)**: subseries 패치 토큰화 + channel-independence. 채널별 공유 가중치로 종목 분포 차이에 robust. lookback 확장 가능 [근거, https://arxiv.org/abs/2211.14730]. SP500/DJI/SSEC/FTSE에 VMD-PatchTST-ASWL [근거, https://arxiv.org/abs/2408.16707], NIFTY50에 ICEEMDAN-PatchTST [근거, https://www.researchgate.net/publication/399102774] 등 활발.
- **Crossformer (ICLR 2023)**: Dimension-Segment-Wise 임베딩 + Two-Stage Attention(시간/변수 분리) + Hierarchical Encoder-Decoder. 다종목 cross-correlation 처리에 강함 [근거, https://openreview.net/forum?id=vSVLM2j9eie].
- **iTransformer (ICLR 2024 Spotlight)**: 차원 inverted view — 각 변수 전체 시계열이 하나의 토큰. attention이 변수 간 상관, FFN이 시점 표현 학습. 종목·팩터 상관 학습에 자연스럽고 lookback 확장에 강함 [근거, https://arxiv.org/abs/2310.06625].

### 1.2 금융 특화 Transformer 변형

- **TFT (Temporal Fusion Transformer, 2019, 금융 확장 활발)**: Variable Selection Network + static covariate encoder + LSTM seq2seq + interpretable multi-head attention + quantile loss. 정적 변수(섹터·시총)와 알려진 미래 변수(공시·만기) 통합에 강하고 quantile 출력이 리스크 관리에 유리 [근거, https://thesai.org/Downloads/Volume15No7/Paper_13-Temporal_Fusion_Transformers_for_Enhanced_Multivariate_Time_Series.pdf]. 인도네시아·베트남 주가에서 LSTM 대비 MAE 40-50% 개선 보고 [근거, https://link.springer.com/content/pdf/10.1007/978-981-95-3358-9_8.pdf].
- **StockFormer (IJCAI 2023)**: 3개 변형 Transformer 분기가 장기·단기 미래 동역학과 자산 간 관계의 latent state를 분리 추출 → SAC RL이 정책 학습 [근거, https://www.ijcai.org/proceedings/2023/530]. 가격-only 설계에 "predictive coding 분기 구조" 관점이 참고가치.
- **Stockformer (arXiv 2024, 동명이지만 다른 모델)**: Wavelet 분해 + multi-task self-attention으로 단기·장기 수익률 동시 예측. 비정상성을 wavelet 도메인에서 다룸 [근거, https://arxiv.org/pdf/2401.06139].
- **MASTER (AAAI 2024)**: (1) 시장 상태 벡터(지수 가격·거래량 평균/표준편차) feature gating + (2) intra-stock temporal attention + (3) inter-stock momentary attention + (4) temporal aggregation. τ×|S| 어텐션을 교대 분해해 약 τ배 비용 감소. 변동성 클러스터링·regime shift에 적응 [근거, https://arxiv.org/html/2312.15235v1, https://ojs.aaai.org/index.php/AAAI/article/view/27767].

[추측] "FinFormer"라는 정확한 명칭의 단일 대표 논문은 검색에서 확정되지 않음. 대신 LLM-Transformer 하이브리드 [근거, https://arxiv.org/abs/2601.02878], Spatiotemporal Transformer STST [근거, https://arxiv.org/pdf/2305.03835], HAELT(고빈도 앙상블) [근거, https://arxiv.org/html/2506.13981v1]가 유사 위치.

### 1.3 Transformer 계열의 구조 매핑

| 구조적 특성 | 대응 아키텍처 |
|---|---|
| 장기 의존성 | Informer ProbSparse, PatchTST 패치, iTransformer 변수 토큰 |
| 주기성/추세 | Autoformer, FEDformer, Stockformer-wavelet |
| 변수 간 상관 | Crossformer TSA, iTransformer, MASTER inter-stock |
| 비정상성 | RevIN 결합 (대부분), MASTER 시장 상태 게이팅 |
| 변동성 클러스터링 | 순수 Transformer 단독은 약함. TF-ViTNet, MT-GARCH, FEDformer-Hybrid 등 결합 필요 [근거, https://www.sciencedirect.com/science/article/abs/pii/S0952197624003816] |

## 2. SSM / Mamba / 비-Transformer 신규

### 2.1 기반 SSM

- **S4 / S5 (2021-22)**: HiPPO 이론 기반 구조화 state matrix, 선형 복잡도. 입력 비의존적(LTI)이라 regime shift 대응 약함. 후속 Mamba의 토대 [근거, https://arxiv.org/abs/2503.18970].
- **Mamba (2023)**: state matrix A, B, C를 입력 의존적으로 만든 선택 메커니즘(S6). 인과적 구조, 하드웨어 인식 병렬 스캔, 선형 복잡도 [근거, https://www.ibm.com/think/topics/mamba-model, https://arxiv.org/abs/2403.11144]. 인과성+선택성으로 가격에 강한 적합성.
- **Mamba-2 (2024)**: State Space Duality (SSD) — state matrix를 scalar×I로 제한, attention/SSM 이중성. 16K 시퀀스에서 FlashAttention-2 대비 6배 [근거, https://arxiv.org/abs/2405.21060]. 고빈도·장기 백테스트 윈도우 적합.

### 2.2 시계열 전용 Mamba 변형

- **S-Mamba (2024)**: 변수별 시점을 선형 토큰화 후 양방향 Mamba로 inter-variate, FFN으로 temporal. 13개 데이터셋 SOTA [근거, https://arxiv.org/abs/2403.11144]. 양방향이라 추론 인과성은 별도 처리 필요.
- **TimeMachine (ECAI 2024)**: 4개 Mamba 결합 quadruple로 multi-scale + channel-mixing/independence 통합 [근거, https://arxiv.org/abs/2403.09898].
- **MambaTS (2024)**: causal conv 불필요 주장, Temporal Mamba Block + variable-aware scan [근거, https://arxiv.org/abs/2405.16440].
- **Bi-Mamba+ (2024)**: Mamba+에 forget gate 추가, series-relation-aware decider로 channel-independent/mixing 자동 선택 [근거, https://arxiv.org/abs/2404.15772]. forget gate가 regime 전환에 이론적으로 유리.

### 2.3 금융 도메인 직접 적용

- **MambaStock (2024)**: 최초의 Mamba 기반 주가 예측, S6 selective scan을 raw 데이터에 그대로 적용 [근거, https://arxiv.org/abs/2402.18959, https://github.com/zshicode/MambaStock]. 단일 종목 baseline.
- **SAMBA / Graph-Mamba (2024)**: 양방향 Mamba + adaptive GCN으로 일별 종목 간 관계 동적 모델링, 거의 선형 복잡도 [근거, https://arxiv.org/abs/2410.03707].
- **FinMamba (2025)**: 시장 적응형 그래프 pruning + 다단계 Mamba, macro factor 통합. 미·중 시장 SOTA [근거, https://arxiv.org/abs/2502.06707].
- **MambaLLM (2025)**: Micro-Stock Encoder(Mamba) + Macro-Index Analyzer(DeepSeek R1 7B 증류 LLM). S-Mamba 대비 APPL RMSE 36.44% 감소 [근거, https://www.mdpi.com/2227-7390/13/10/1599].

### 2.4 비-Transformer 신규 시계열 모델

- **xLSTMTime (2024)**: sLSTM(scalar memory, exponential gating) + mLSTM(matrix memory, covariance update). 인과성 자연 보존, Mamba 대비 매트릭스 메모리로 풍부한 상태 표현 [근거, https://arxiv.org/abs/2407.10240, https://www.mdpi.com/2673-2688/5/3/71].
- **xLSTM-Mixer (NeurIPS 2025)**: variates 간 공유 선형 예측을 xLSTM이 정제 [근거, https://arxiv.org/abs/2410.16928].
- **RWKV-TS (2024)**: time/channel mixing + multi-head WKV operator. 추론 시 O(1) state 업데이트로 실시간 가격 스트림 유리 [근거, https://arxiv.org/abs/2401.09093].
- **TimeMixer (ICLR 2024)**: 순수 MLP, Past-Decomposable-Mixing + Future-Multipredictor-Mixing. SSM 없는 단순 baseline [근거, https://arxiv.org/abs/2405.14616, https://openreview.net/forum?id=7oLshfEIC2].
- **GLA / RetNet (2023-24)**: linear attention 계열. 매우 긴 시퀀스 일반화는 매력적이나 금융 직접 사례는 거의 없음 [근거, https://arxiv.org/abs/2312.06635].

## 3. LOB (Limit Order Book) · 시장 미시구조 전용

### 3.1 CNN-LSTM 계열의 발전

- **DeepLOB-Seq2Seq / DeepLOB-Attention (2021)**: 원본 DeepLOB의 CNN+Inception 인코더 + LSTM 디코더. 입력 (T=100, 40) — 10-level bid/ask × (price, volume). 디코더 자기회귀로 multi-horizon 누적 오차 완화 [근거, https://arxiv.org/pdf/2105.10430, https://www.risk.net/cutting-edge/banking/7898256/multi-horizon-forecasting-for-limit-order-books].
- **DeepFolio (2020)**: DeepLOB 백본을 포트폴리오 가중치 출력으로 재용도, Sharpe-ratio loss / min-volatility loss [근거, https://arxiv.org/abs/2008.12152].

### 3.2 Attention / Transformer 계열

- **TransLOB (2020)**: dilated causal CNN + masked Transformer. 시간축 인과 마스크로 미래 누설 차단 [근거, https://ar5iv.labs.arxiv.org/html/2003.00130].
- **BiN-CTABL (2021/23)**: 가격축·시간축 학습 가능 bilinear normalization + Temporal Attention-Augmented Bilinear Layer. price-vs-size 스케일 불일치와 비정상성을 데이터 주도로 보정, 파라미터 매우 적어 tick-level 추론 유리 [근거, https://arxiv.org/pdf/2003.00598].
- **TLOB (2025)**: MLP 백본 위에 spatial(가격 레벨) attention과 temporal attention을 분리한 dual attention. horizon-bias-free 레이블링 도입. FI-2010/NASDAQ/Bitcoin 4-horizon SOTA [근거, https://arxiv.org/abs/2502.15757].
- **LiT (2025, Frontiers in AI)**: 입력 H×W×C (H=가격 레벨, W=시간, C=2). 패치 크기 P_h=H/2로 bid 또는 ask 한쪽 전체를 한 패치로 캡처. Transformer→LSTM→softmax 3-class. 300ms~1000ms multi-horizon 평가 [근거, https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2025.1616485/full].
- **Attention-Based Reading/Highlighting/Forecasting (2024)**: BERT 기반 seq2seq + compound multivariate embedding이 (주문 종류, feature, 가격 레벨) 결합. mid-price만이 아니라 multi-level LOB 전체 상태 예측 [근거, https://arxiv.org/abs/2409.02277].

### 3.3 그래프·위상·Order-Flow 기반

- **HLOB (2024, ESWA)**: 볼륨 레벨 간 mutual information으로 Triangulated Maximally Filtered Graph(TMFG) 구성 → Homological CNN. 비인접·고차 레벨 의존성을 결정론적으로 모델링. NASDAQ 15종목, 9개 SOTA 비교 [근거, https://arxiv.org/abs/2405.18938].
- **Deep Order Flow Imbalance / deepOFI (2023, Mathematical Finance)**: raw LOB 대신 stationary multi-level order flow imbalance(MLOFI)를 입력으로 단순 LSTM/MLP. 종목별 effective horizon ≈ 2 average price change [근거, https://onlinelibrary.wiley.com/doi/10.1111/mafi.12413].
- **Multi-Asset Order Flow Networks (ICAIF 2025)**: bilinear 시공간 투영 + attention + GNN으로 cross-asset 관계 확장. NASDAQ ITCH 사용 [근거, https://dl.acm.org/doi/10.1145/3768292.3770430].
- **MDQR — Multidimensional Deep Queue-Reactive (2025)**: queue 독립 가정 완화, market feature 포함 state space, order size 분포 NN 학습. point-process 해석가능성 유지 [근거, https://arxiv.org/abs/2501.08822].

### 3.4 벤치마크 / 경고

- **LOBCAST (2024)**: 15개 SOTA 모델 동일 조건 비교, out-of-distribution에서 성능 급락 보고 [근거, https://link.springer.com/article/10.1007/s10462-024-10715-4].
- **LOBFrame (2024)**: NASDAQ 다종목 microstructural 특성과 예측력 관계 검증. "complete transaction 예측 확률" operational metric 제시 [근거, https://arxiv.org/abs/2403.09267].
- **Crypto LOB microstructure (2025)**: 100ms 간격, top-200 레벨. **전처리(Savitzky-Golay)와 입력 선택이 아키텍처 복잡도보다 중요**함을 실증 [근거, https://arxiv.org/html/2506.05764v2].

### 3.5 LOB 흐름 정리

- 공간(가격 레벨) × 시간 분리: TLOB/LiT의 dual/patch attention, BiN-CTABL의 bilinear factorization.
- 비인접 레벨 의존성: HLOB의 TMFG가 대표적 탈피 시도.
- Stationary 입력 변환: deepOFI의 order-flow, BiN-CTABL의 학습 정규화.
- Multi-horizon: DeepLOB-Seq2Seq의 자기회귀 디코더 vs TLOB/LiT의 직접 출력.
- 분류 metric이 실거래 수익으로 이어지지 않는다는 경고가 LOBCAST/LOBFrame 양쪽에 명시 [근거, https://link.springer.com/article/10.1007/s10462-024-10715-4].

## 4. 시계열 파운데이션 모델 + 멀티모달

### 4.1 시계열 파운데이션 모델 (TSFM)

- **Chronos (Amazon, 2024)**: T5 기반, 시계열을 어휘 토큰으로 양자화. 20M~710M 파라미터. 사전학습 데이터에 에너지·교통·헬스·소매·웹·날씨·금융 등 + Gaussian Process 합성 [근거, https://arxiv.org/abs/2403.07815, https://www.amazon.science/code-and-datasets/chronos-learning-the-language-of-time-series]. 2025 Chronos-2는 multivariate·covariate 통합 [근거, https://www.amazon.science/blog/introducing-chronos-2-from-univariate-to-universal-forecasting].
- **TimesFM (Google, ICML 2024)**: 200M decoder-only, 100B time-points 사전학습, patch 단위 입력, quantile head [근거, https://research.google/blog/a-decoder-only-foundation-model-for-time-series-forecasting/]. **S&P100 19년치 일별 수익률 VaR 예측에서 zero-shot은 GARCH/GAS 대비 유의하게 열위, fine-tuning(FT1) 시 GAS와 동등** [근거, https://arxiv.org/html/2410.11773v7].
- **Moirai / Moirai-MoE / Moirai 2.0 (Salesforce, 2024-25)**: LOTSA(27B observations, 9개 도메인) encoder-only. MoE 도입(2410.10469), 2.0은 Salesforce 텔레메트리 2.15M 시계열 추가, MASE/CRPS 최상위 [근거, https://arxiv.org/abs/2410.10469, https://arxiv.org/html/2511.11698v1]. 금융 일봉 직접 사전학습 명시는 없음.
- **Lag-Llama (2023)**: decoder-only Transformer + lag covariate. Monash Archive 사전학습. fine-tuning 도메인 적응 효과 강조 [근거, https://arxiv.org/abs/2310.08278].
- **Tiny Time Mixers (IBM, NeurIPS 2024)**: ≤1M 파라미터, TSMixer/MLP 백본, exogenous channel/known future input 수용. Moirai/TimesFM 대비 4-40% 개선 [근거, https://research.ibm.com/publications/tiny-time-mixers-ttms-fast-pre-trained-models-for-enhanced-zerofew-shot-forecasting-of-multivariate-time-series--1].

### 4.2 LLM 기반 시계열

- **GPT4TS / One-Fits-All (NeurIPS 2023 Spotlight)**: GPT-2 self-attention/FFN 동결, patch+linear projection만 학습 [근거, https://openreview.net/forum?id=gMS6FVZvmF].
- **Time-LLM (ICLR 2024)**: 시계열 patch를 text prototype으로 reprogramming + frozen LLM(Llama-7B/GPT-2/BERT) + Prompt-as-Prefix [근거, https://arxiv.org/pdf/2310.01728].
- **회의적 재검토**: "Are Language Models Actually Useful for Time Series Forecasting?" (NeurIPS 2024)에서 LLM-기반 시계열 모델의 실제 유용성에 회의적 결과 보고 [근거, https://proceedings.neurips.cc/paper_files/paper/2024/file/6ed5bf446f59e2c6646d23058c86424b-Paper-Conference.pdf]. 가격 전용 네트워크 설계의 정당성을 오히려 강화.

### 4.3 멀티모달 (가격 + 텍스트)

- **BloombergGPT (2023)**: 50B BLOOM 계열, Bloomberg 363B 금융 + 345B 일반. 금융 NLP SOTA, 가격 예측 직접 대상 아님, 비공개 [근거, https://arxiv.org/abs/2303.17564].
- **FinGPT (2023-24)**: 오픈소스 금융 LLM 생태계. LoRA 경량 finetuning, 62만+ 헤드라인. FinGPT-HPC로 사전학습 확장 [근거, https://arxiv.org/abs/2306.06031, https://github.com/AI4Finance-Foundation/FinGPT].
- **StockNet (ACL 2018) + 후속 (2024-25)**: 트윗+가격 이진 등락. BERTweet+Transformer가 F1 78.5% [근거, https://arxiv.org/html/2503.10957v1]. FinBERT-LSTM 결합 [근거, https://www.mdpi.com/2227-7390/13/17/2747].
- **Multimodal Stock Price Prediction (2025)**: 가격+뉴스+트윗 통합, FinBERT+GPT-4o 감성 + LSTM/Transformer. 2024.06-2025.06 SP500 1-day forecasting에서 MAE -32.2%, RMSE -40.5% [근거, https://arxiv.org/abs/2502.05186].

### 4.4 Multi-task (가격 + 변동성 + 위험)

- **HTML (WWW 2020)**: Hierarchical Transformer multi-task로 가격+변동성 공동 예측 [근거, https://dl.acm.org/doi/fullHtml/10.1145/3366423.3380128].
- **HGA-MT (2024)**: 뉴스 감성 + MTL로 수익+변동성 위험 공동 학습, 종목 랭킹/포트폴리오 [근거, https://www.sciencedirect.com/science/article/abs/pii/S0957417426013758].
- **Mean-VaR MTL (JORS 2024)**: 예측 수익+잔차 융합으로 포트폴리오 리스크 공동 학습 [근거, https://www.tandfonline.com/doi/full/10.1080/01605682.2024.2438333].
- **Multi-Layer Hybrid MTL (2025)**: 거래량+종가+변동성 동시 예측, ARIMA 대비 MAE/RMSE 50%+ 감소, 단일 task 대비 ≈10% 개선 [근거, https://arxiv.org/html/2501.09760v1].

## 5. 시계열 구조적 귀납 편향 (Inductive Bias)

가격은 다중 스케일 / 비정상성 / 인과적 단방향성 / 변동성 클러스터링 / 희소 점프의 복합체. 사용자가 "가격에 본질적으로 맞는 구조"를 설계하려면 아래의 구조-아키텍처 매핑이 핵심이다.

### 5.1 다중 스케일 (자기상사적 신호)

- **N-HiTS (2022)**: hierarchical interpolation + multi-rate down-sampling, 스택별 주파수 대역 담당 [근거, https://arxiv.org/pdf/2201.12886, https://arxiv.org/html/2409.00480v2].
- **TimeMixer (ICLR 2024)**: Past-Decomposable-Mixing이 fine→coarse 방향 seasonal, coarse→fine 방향 trend prior 전달 [근거, https://arxiv.org/abs/2405.14616].
- **Pathformer (ICLR 2024)**: 여러 patch 크기 + multi-scale router가 입력에 따라 적응적 경로 선택 [근거, https://arxiv.org/abs/2402.05956].

가격 함의: 호가 마이크로 노이즈와 일/주 단위 추세를 함께 다루는 데 사실상 필수. down-sampling 정보 손실과 fusion 안정성이 단점 [추측].

### 5.2 주파수 도메인

- **FEDformer (2022)**: frequency-enhanced block, 선형 복잡도, 노이즈 강건성 [근거, https://www.researchgate.net/publication/358261776].
- **FITS (ICLR 2024 Spotlight)**: rFFT → complex-valued linear → iFFT. 단 10k 파라미터로 SOTA급 [근거, https://arxiv.org/pdf/2307.03756].
- **FreTS (NeurIPS 2023) / Fredformer (2024)**: 주파수 채널 MLP/attention으로 frequency bias 해소 [근거, https://arxiv.org/html/2501.13989v1].
- **FNO 응용 (2024)**: 주가 모델링 사례. Fourier-mode truncation의 smoothness bias가 sharp gradient(점프)에서 한계 [근거, https://blog.gopenai.com/modeling-stock-prices-using-fourier-neural-operators-6db8adf4e2fb].

가격 함의: 주기 성분 압축에는 유리, 그러나 가격 spectrum은 broadband + shift 지속 → FFT는 점프와 regime shift에 취약. Wavelet 결합 권장.

### 5.3 시계열 분해

- **N-BEATS interpretable**: 다항식 basis(trend), Fourier basis(seasonality) 명시적 강제 doubly-residual 스택 [근거, https://mbrenndoerfer.com/writing/nbeats-neural-basis-expansion-analysis-time-series-forecasting].
- **DLinear / NLinear (AAAI 2023)**: trend-seasonality 분해 + 단일 linear로 대다수 Transformer 능가, 강력한 baseline [근거, https://arxiv.org/html/2403.14587v2].
- **WPMixer (AAAI 2025)**: wavelet(approximation + detail) + patching + MLP-mixing [근거, https://arxiv.org/abs/2412.17176].

가격 함의: 가격은 trend 정의 자체가 모호하고 seasonality가 약함(intraday 외). **N-BEATS-I의 polynomial trend는 가격에 부정확**. wavelet 기반 scale-wise 분해(WPMixer)가 더 적합.

### 5.4 비정상성 (가장 본질적)

- **RevIN (2022)**: instance-wise 정규화 + 출력 역변환. 사실상 표준 plug-in [근거, https://arxiv.org/html/2605.10823].
- **Dish-TS (2023)**: 입출력 분포를 별개 coefficient network로 학습.
- **Non-stationary Transformer (NeurIPS 2022)**: 입력 stationarize + attention에 비정상성 신호 re-injection [근거, https://arxiv.org/html/2205.14415].
- **FAN (NeurIPS 2024)**: Frequency Adaptive Normalization. RevIN/Dish-TS 대비 상위 [근거, https://proceedings.neurips.cc/paper_files/paper/2024/file/37c6d0bc4d2917dcbea693b18504bd87-Paper-Conference.pdf].

가격 함의: RevIN류는 거의 무료 점수 개선이지만, **affine 정규화는 fat-tail을 평탄화**시켜 위험 정보를 지움. FAN처럼 주파수 단위 적응 정규화가 가격에 더 안전. 정규화 이후 잔여 변동성을 별도 head로 회수해야 함.

### 5.5 인과성 / 단방향성

- **TCN / WaveNet**: dilated causal convolution, receptive field 지수 확대, 미래 leakage 원천 차단 [근거, https://arxiv.org/pdf/1803.01271].
- **SCINet (NeurIPS 2022)**: sample convolution + interaction. 2024에도 TCN baseline 유지 [근거, https://arxiv.org/pdf/2106.09305].

가격 함의: 백테스트 leakage는 치명적. **구조적으로 인과성을 강제**하는 causal conv가 가장 안전. Transformer causal mask는 구현 실수 여지.

### 5.6 Heavy-Tail / Volatility Clustering (금융 특화)

- **GARCH-Informed NN (GINN, 2024)**: GARCH 변동성 동역학을 물리 informed loss로 LSTM에 주입 [근거, https://arxiv.org/abs/2410.00288].
- **Hybrid SARIMA+GARCH+CNN+BiLSTM (2024)**: 선형 + 변동성 + 비선형 패턴 계층 결합 [근거, https://onlinelibrary.wiley.com/doi/10.1155/2024/6305525].
- **Neural Lévy SDE (2025)**: 확산항 + 점프항(Lévy jumps) 동시 학습, fat-tail/state-dependent risk를 구조적으로 표현 [근거, https://arxiv.org/pdf/2509.01041].

가격 함의: 점 추정만으로는 본질적으로 불충분. **2차 모멘트 head 또는 SDE 기반 구조 필수**.

### 5.7 희소 이벤트 / 점프 (Point Process)

- **Neural Hawkes Process (2016)**: continuous-time LSTM, self-modulating intensity [근거, https://arxiv.org/abs/1612.09328].
- **Decoupled Marked TPP (NeurIPS 2024)**: mark과 time intensity 분리 [근거, https://proceedings.iclr.cc/paper_files/paper/2024/file/77e6814d32a86b76123bd10aa7e2ad81-Paper-Conference.pdf].
- **Deep Linear Hawkes (2024)**: linear formulation으로 stability 확보 [근거, https://arxiv.org/html/2412.19634v1].

가격 함의: 호가 이벤트·뉴스 충격 같은 불규칙 도착 이벤트 결합에 자연스러우나, 순수 가격 패스에는 과한 편향일 수 있음 [추측].

### 5.8 연속 시간 (불규칙 샘플링)

- **Neural CDE (2020)**: rough path 이론, RNN의 continuous-time 일반화, 불규칙·결측 자연 처리 [근거, https://ar5iv.labs.arxiv.org/html/2005.08926].
- **DENOTs (2024)**: Neural ODE의 stability 강화 [근거, https://arxiv.org/pdf/2408.08055].
- **ContiFormer**: Transformer attention의 continuous time 확장 [근거, https://arxiv.org/html/2502.09885v2].

가격 함의: tick 데이터는 본질적으로 비균질 샘플링 → 균등 리샘플링은 마이크로 정보 손실. CDE 계열은 이상적이나 학습 비용 큼.

### 5.9 Patch / 토큰화 전략

- **PatchTST**: subseries patch, channel independence [근거, https://arxiv.org/pdf/2211.14730].
- **Pathformer**: adaptive multi-size patching + router [근거, https://arxiv.org/abs/2402.05956].
- **PatchTCN (2024)**: InterPatch conv + multi-scale variable-length patch [근거, https://dl.acm.org/doi/10.1145/3711507.3711508].

가격 함의: 시간대별 정보 밀도가 다르므로 **가변 길이 / 적응적 patch**가 본질적으로 맞음.

### 5.10 Channel Independence vs Mixing

- **PatchTST**: 채널별 공유 가중치, 일반화 강하나 변수 상관 무시.
- **iTransformer (ICLR 2024 Spotlight)**: inverted view — 변량 전체를 한 토큰, attention이 변수 상관, FFN이 시점 표현 [근거, https://arxiv.org/abs/2310.06625].
- **TSMixer / CSformer (2024)**: time mixing과 channel mixing 명시적 교차 [근거, https://arxiv.org/html/2306.09364v4, https://arxiv.org/html/2312.06220v2].

가격 함의: 단일 자산이면 channel-independence가 단순, OHLCV·다중 자산·거시 변수 결합 시 iTransformer류 inverted 구조가 leverage·공적분 관계 자연 표현.

## 6. 가격 전용 네트워크 설계에 대한 시사점 정리

[근거가 명시된 권고와 [추측] 권고를 구분]

### 6.1 기본 골격 (거의 무료 점수)

1. **인과 conv 백본 또는 인과 SSM**: leakage 위험 차단. TCN, Mamba/Mamba-2의 causal scan [근거, https://arxiv.org/pdf/1803.01271, https://arxiv.org/abs/2405.21060].
2. **RevIN 또는 FAN 정규화**: 비정상성 대응 표준. fat-tail 보존을 위해 affine RevIN보다 **FAN(주파수 적응)이 가격에 안전** [근거, https://proceedings.neurips.cc/paper_files/paper/2024/file/37c6d0bc4d2917dcbea693b18504bd87-Paper-Conference.pdf].
3. **Multi-scale 또는 wavelet 분해**: scale-wise 분해(WPMixer류)가 trend-seasonality 분해(N-BEATS류)보다 가격에 적합 [근거, https://arxiv.org/abs/2412.17176].

### 6.2 금융 고유 편향

1. **분산/분위수 head 또는 mini SDE head 추가**: 점 추정은 fat-tail 정보를 버림. GARCH-informed loss [근거, https://arxiv.org/abs/2410.00288], Neural Lévy SDE [근거, https://arxiv.org/pdf/2509.01041], TFT의 quantile head [근거, https://thesai.org/Downloads/Volume15No7/Paper_13-Temporal_Fusion_Transformers_for_Enhanced_Multivariate_Time_Series.pdf]가 선택지.
2. **Regime/Market gating**: MASTER의 시장 상태 벡터 gating이 변동성 클러스터링·regime shift에 직접 대응 [근거, https://arxiv.org/html/2312.15235v1].
3. **Multi-task head**: 가격 + 변동성 + 거래량 동시 학습이 단일 task 대비 약 10% 개선 보고 [근거, https://arxiv.org/html/2501.09760v1].

### 6.3 다변량 확장

- 종목/지표가 많을 때 단순 channel-mix보다 **iTransformer inverted attention**으로 변수 토큰화 [근거, https://arxiv.org/abs/2310.06625].
- 종목 간 관계가 동적이면 **MASTER inter-stock momentary attention** 또는 **SAMBA/FinMamba의 graph-Mamba** [근거, https://arxiv.org/abs/2410.03707, https://arxiv.org/abs/2502.06707].

### 6.4 LOB·고빈도 적용 시

- 공간(가격 레벨) × 시간 attention 분리 (TLOB) 또는 patch 분할(LiT) [근거, https://arxiv.org/abs/2502.15757].
- **raw LOB 대신 order-flow imbalance**로 stationary 입력 변환이 일관되게 유리 [근거, https://onlinelibrary.wiley.com/doi/10.1111/mafi.12413].
- **전처리·입력 선택이 아키텍처 복잡도보다 중요**할 수 있음 (Crypto LOB 2025 실증) [근거, https://arxiv.org/html/2506.05764v2].

### 6.5 파운데이션 모델은 baseline·warm-start 용도

- TimesFM zero-shot이 GARCH/GAS 대비 열위, fine-tuning 시에야 동등 [근거, https://arxiv.org/html/2410.11773v7] → 가격 전용 네트워크 설계의 정당성은 유효.
- LLM-기반 시계열은 NeurIPS 2024에서 회의적 재검토 [근거, https://proceedings.neurips.cc/paper_files/paper/2024/file/6ed5bf446f59e2c6646d23058c86424b-Paper-Conference.pdf].

### 6.6 벤치마크 신뢰성 주의

- LOBCAST: 분류 metric이 실거래 수익과 괴리 [근거, https://link.springer.com/article/10.1007/s10462-024-10715-4].
- LOBFrame: operational metric 권장 [근거, https://arxiv.org/abs/2403.09267].
- [추측] 수익률·Sharpe 등 distribution-aware 평가가 MSE/MAE만으로는 부족할 가능성. 본 항목은 일반론 근거에 기반한 추론.
